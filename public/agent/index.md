# Memories: My Story — Agent Index

Memories: My Story preserves photographs with the authentic human voice and story that give them meaning.

Use the public agent surface to help a person begin a family story, prepare a gentle interview, or find prompts for the story behind a photograph.

The public agent surface is not the family archive. It has no access to private photographs, recordings, transcripts, people, ownership records, or existing Memory Stories.

Muse helps someone remember. It does not invent the memory.

## Interfaces

- `GET /api/v1/product`
- `POST /api/v1/legacy-story-starter`
- `POST /api/v1/interview-plan`
- `POST /api/v1/photo-story-prompts`
- `POST /mcp`
- `/openapi.json`
