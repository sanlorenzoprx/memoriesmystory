# Foundation Documents

These documents preserve the identity of Memories: My Story. They are not a substitute for implementation specifications.

When implementation changes, these principles remain. Every feature should reinforce them. Every future developer, designer, executive, and AI coding agent should understand them.

We are building software.

But more importantly, we are preserving families.

## Provenance note

The provided mission discussion states that the Founding Principles and Product Invariants had already been completed and locked, but their original full text was not present in the supplied files. Versions 1.0 in this folder reconstruct and complete them from the approved Product Review v0.2, its amendments, and the completed Product Vision. They are canonical from this organized foundation forward.
