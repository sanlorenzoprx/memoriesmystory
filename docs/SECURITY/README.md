# Security Controls

Start with `SECRETS_AND_CONFIGURATION.md`. Security and privacy decisions must remain traceable to the Phase 1 specification and must never weaken immutable originals, private-by-default access, truthful durability, or human/generated separation.

Dependency advisories, and the reason for each accepted one, are recorded in `DEPENDENCY_ADVISORIES.md`. CI fails on any high or critical advisory in shipped dependencies.
