# Domain

Own framework-independent concepts here: Memory Story, media asset and derivative provenance, transcript revision, truth state, person, relationship, contribution, album, ownership, sharing event, entitlement, agreement version, deletion state, and legacy custodian.

Packet 1 establishes the executable Phase 1 contracts for branded identifiers, recoverable draft transitions, immutable originals, truthful completion requirements, testimony/generated distinctions, free-story entitlement, idempotency, and durable asset receipts. Domain code does not import React, Worker bindings, or provider SDKs.
